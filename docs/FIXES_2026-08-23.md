## 9. v4.1 Fixes (2026-08-26)

### Weapons
- `RecoilController.ts` AK-47 pattern bullets 16-29: X values flipped from negative (left hook) to positive (right hook) per "7" shape doc
- `useWeaponStore.ts` `finishReload`: now deducts `reserveAmmo` by `mag - currentAmmo` (clamped); added `reserveAmmo` to `WeaponState` interface and `equipWeapon` initialization — fixes infinite ammo exploit
- `Offline5v5Store.ts` `localBuy`: added `already_owned` guard — cannot re-buy primary/secondary weapon you already hold

### Zombie Engine (P0 Critical)
- `ZombieEngine.ts` **complete rewrite** — 6 critical fixes:
  1. **`applyAcidDot` setInterval → frame-based** `acidDots: AcidDot[]` array ticked in `update(dt)`. Eliminates timer leak on game restart / wave clear
  2. **`aliveCount()` O(N) scan → `_aliveCount` counter** incremented on spawn, decremented on kill/exploder/nuke
  3. **`window.dispatchEvent` → `zombieEvents` EventBus** (`ZombieEventBus` class with `on/off/emit`) — all 6 event types converted
  4. **Wave formula fixed**: `6+(wave-1)*4` per `WAVE_CONFIG` (was `6+wave*3`)
  5. **PowerUp drop chance**: 0.05 → 0.15 per doc
  6. **`ZOMBIE_CFG` synced to `shared/ZOMBIE_TYPES` + `ZOMBIE_POINTS`** — no more hardcoded values
- `shared/index.ts` `PowerUpType`: `"carpenter"|"fire_sale"` replaced with `"speed_cola"|"juggernog"` to match store usage

### Grenades
- `GrenadeSystem.tsx` training HE splash: radius 6m→4m, max damage 85→80 per doc

### L4D
- `L4DDirector.ts` `randomSpawnAroundSurvivors`: now clamps to `[-halfW, halfW]` x `[-halfLen, halfLen]` where `halfLen = 36*scale` per chapter — zombies no longer spawn outside map
