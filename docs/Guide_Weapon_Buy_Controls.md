## 🛒 1. Panduan Membeli Senjata & Perlengkapan (Buy Menu)

### 📌 Syarat Membuka Buy Menu:
1. Pemain berada di **Buy Zone** tim masing-masing:
   - **Tim Terrorist (T):** Area spawn merah (`[-25, 0, 0]`)
   - **Tim Counter-Terrorist (CT):** Area spawn biru (`[25, 0, 0]`)
2. Ronde berada pada **Buy Phase** (15 detik awal ronde).

### ⌨️ Tombol Akses:
- **Tekan `B`**: Membuka / menutup hamparan **Buy Menu**.

## 🔫 2. Panduan Mengganti Slot Senjata (Hotkeys 1, 2, 3, 4)

Sistem senjata CS Web FPS menggunakan **Slot Senjata CS:GO Standard**:

```
[ 1 ] Senjata Utama (Primary Rifle / SMG / Sniper)
  └── AK-47 / M4A1-S / AWP / MP5

[ 2 ] Senjata Pistol (Secondary Handgun)
  └── Desert Eagle

[ 3 ] Pisau (Melee Knife)
  └── Pisau Komando (+10% Kecepatan Lari)

[ 4 ] Granat & Utilitas (Grenade / Utility)
  └── HE Grenade / Smoke / Flashbang (Juga bisa tekan 'G')
```

### ⚡ Fitur Khusus Pisau (Slot 3):
- Mengganti ke pisau (**Tombol 3**) memberikan **Speed Buff +10%** (kecepatan lari meningkat dari 7.5 m/s menjadi 8.25 m/s), memungkinkan *rotation* & *slide-hop* lebih cepat.

## 🎮 3. Daftar Kontrol Lengkap (Full Controls Reference)

| Tombol Keyboard / Mouse | Fungsi Utama | Detail Mekanis |
| :--- | :--- | :--- |
| **`W` `A` `S` `D`** | Pergerakan Pemain | Maju, Kiri, Mundur, Kanan |
| **`Shift`** | Sprint / Lari Cepat | Meningkatkan kecepatan ke 7.5 m/s |
| **`Ctrl`** | Jongkok / Crouch | Mengurangi tinggi kapsul & *recoil spread* |
| **`Shift` + `Ctrl`** | **Slide (Meluncur)** | Meluncur di lantai dengan dorongan kecepatan |
| **`Space`** | Lompat / Jump | *Slide-hop chain* jika ditekan pas saat mendarat |
| **`Klik Kiri (Mouse 1)`** | Menembak / Serang | Menembak senjata aktif / Tebasan pisau |
| **`Klik Kanan (Mouse 2)`** | ADS / Zoom Scope | Zoom FPV (FOV 75 → 60) / Scope AWP |
| **`1`** | Slot Senjata Utama | Mengganti ke AK-47 / M4A1-S / AWP / MP5 |
| **`2`** | Slot Pistol | Mengganti ke Desert Eagle |
| **`3`** | Slot Pisau | Mengganti ke Pisau Komando (+10% Speed) |
| **`4`** / **`G`** | Lempar Granat | Melempar HE / Asap / Flashbang |
| **`B`** | Buy Menu | Membuka toko senjata di Buy Zone |
| **`R`** | Reload | Mengisi ulang magasin peluru |
| **`E`** | Interaksi / Plant / Defuse | Menanam C4 (3s) / Menjinakkan C4 (5s/10s) |
| **`M`** | Radar / Minimap 2D | Membuka/menutup radar 2D di layar |
| **`TAB`** | Leaderboard / Skor | Menampilkan tabel skor pertempuran |
